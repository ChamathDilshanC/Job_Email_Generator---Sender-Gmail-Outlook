# Changelog

This file records notable project changes. Releases are also published through GitHub Releases when a `vX.Y.Z` tag is pushed.

## Unreleased

- Added six role-targeted application templates:
  - Intern Software Engineer
  - Associate Software Engineer
  - Intern DevOps Engineer
  - Associate DevOps Engineer
  - IT Support Specialist
  - Software Developer
- Added per-template skill customization with add/remove controls, three-column organization, and reset-to-profile behavior.
- Template skill overrides are isolated from the main `Your Information` skills.
- Every skill selected for a template is rendered in the generated email; the previous six-skill display cap was removed.
- Added a larger send-email preview window.
- Made light/dark theme changes instant by disabling transition effects during the theme switch.
- Simplified the résumé attachment note to a bold, black, two-line paragraph.

## 1.5.3

- Current application version recorded in `package.json`.
- Includes Gmail/Outlook sending, background scheduled Gmail delivery, AI-assisted resume parsing, resume profiles, email history, open tracking, cover letters, DevResume integration, and the template gallery.
